# Intro
Este MVP consiste en el diseño e implementación de un sistema de monitoreo ambiental, en el cual, mediante sensores virtuales, se recopilan datos como temperatura, humedad y calidad del aire, los cuales son enviados a una plataforma de Cloud Computing.
El desarrollo del MVP debe contemplar la simulación de los sensores, la comunicación con Cloud Computing y los servicios Cloud aprovisionados para la recepción de los datos.
El objetivo del workshop es fomentar el uso de tecnologías digitales emergentes, específicamente Internet of Things (IoT) y Cloud Computing, dentro de un contexto de transformación digital.
